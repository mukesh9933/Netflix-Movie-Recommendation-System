# Netflix Movie Recommendation System

## Overview
This project builds a movie recommendation system that predicts user preferences and recommends movies using collaborative filtering techniques.

The system analyzes historical movie ratings and identifies patterns between users and movies to generate personalized recommendations.

## Features
- Collaborative filtering recommendation system
- Implementation of SVD and KNN algorithms
- Exploratory Data Analysis (EDA)
- Model evaluation using RMSE
- Visualization of rating patterns

## Tech Stack
- Python
- Pandas
- Matplotlib
- Seaborn
- Surprise (Recommendation System Library)

## Algorithms Used

### 1. SVD (Singular Value Decomposition)
Matrix factorization technique used to learn hidden user preferences and movie features.

### 2. KNN (K-Nearest Neighbors)
Similarity-based recommendation approach that finds similar users or movies.

## Project Workflow
1. Data Loading
2. Exploratory Data Analysis
3. Data Preprocessing
4. Model Training
5. Model Evaluation
6. Movie Recommendation

## Evaluation Metric
The model performance is evaluated using **RMSE (Root Mean Square Error)**.

Lower RMSE indicates better prediction accuracy.
